# Tab MRU Toggle

縦タブ（vertical sidebar）の並びを「元の順」と「最後に触った順（MRU）」でワンタッチ切り替えするChrome拡張のプロトタイプ。おまけで、1週間以上触っていないタブのタイトルに 💤 マークを付け、同じタイトルのタブが複数あるときは URL の違う部分を `[ラベル]` として付けて区別できるようにする。さらに localhost などローカル環境のタブには 🟢 を付けて、本番環境のタブと見分けられるようにする。

Chromeの縦タブはタブ順序をそのまま縦に表示しているだけなので、`chrome.tabs.move` で順序を切り替えれば縦タブにもそのまま反映される（拡張独自のUIは不要）。

## 使い方

- **ツールバーの拡張アイコンをクリック**、またはショートカット **⌥M（Alt+M）** でモード切り替え
- 現在のモードはツールバーアイコンで分かる:
  - 通常（元の順）: グレーのアイコン
  - MRUモード中: ブルーのアイコン＋`MRU`バッジ
  - ホバーのツールチップに「クリックすると何が起きるか」を表示

### MRUモード ON にすると

1. その瞬間の並び順とグループ構成（タイトル・色・折りたたみ）をスナップショット
2. タブグループを全解体し、全タブを並列に扱う
3. `lastAccessed` 降順（＝最近触った順）で即座に並べ替え
4. 以降、タブをアクティブにするたびにそのタブが最上部（ピン留めの直後）へ移動

### OFF に戻すと

- スナップショットの順序に復元し、グループも作り直してタイトル・色・折りたたみ状態を戻す
- MRUモード中に開いた新規タブは「開き元タブの直後、なければ末尾」に挿入される

### 放置タブの 💤 マーク

- 1時間ごとに全タブをチェックし、最後にアクティブにしてから **一定日数以上**（デフォルト7日）経ったタブのタイトル先頭に「💤 」を付ける
- 日数の閾値は**オプションページ**（`chrome://extensions` → 拡張の「詳細」→「拡張機能のオプション」、またはツールバーアイコンを右クリック →「オプション」）で 1〜365 日に変更できる。変更は即時反映
- そのタブをアクティブにすると即座に外れる
- タブの並び順・グループには一切影響しない（MRUモードとも独立）

### 💤 タブの一括クローズ

- **ツールバーアイコンを右クリック →「💤 が付いたタブをすべて閉じる」**、またはオプションページのボタンで、💤 マークが付いているタブをまとめて閉じられる
- 対象は「実際に 💤 が付いているタブ」だけ（見えている通りに閉じる）。アクティブタブとピン留めタブは閉じない
- 閉じた件数がバッジに2秒間表示される。誤って閉じた場合は Chrome の「最近閉じたタブ」（⌘⇧T）で復元できる

### 同名タブの区別（`[ラベル]`）

- 同じウィンドウ内に同じタイトルのタブが2つ以上あると、URL を「ホスト名 → パスの各段 → クエリ → ハッシュ」の順に比べて**最初に違う要素**をタイトル先頭に `[ラベル] ` として付ける
  - サイトが違う: `[github.com] ログイン` / `[gitlab.com] ログイン`
  - 同じサイトでパスが違う: `[issues] repo · GitHub` / `[pulls] repo · GitHub`
  - 検索語だけ違う: `[q=foo] Google 検索` / `[q=bar] Google 検索`
  - URL まで完全に同じ: `[#1]` `[#2]` …（作成順）
  - UUID などの長い ID は先頭8文字に切り詰める
- タイトル変更・タブを閉じた時に即再計算し、重複が解消されたらラベルも外れる。💤 と併用時は `💤 [ラベル] タイトル` の順
- 自分が付けたラベルだけを記録して剥がすので、ページ本来のタイトルが `[PATCH] …` のように始まっていても壊さない
- オプションページでオフにできる（オフにすると全ラベルを外す）。ピン留めタブは対象外
- 💤 と同じ仕組みなので、`chrome://` 等の保護ページと休止中のタブにはラベルを付けられない（比較対象には含まれる）

### ローカル環境タブの目印（🟢）

- URL のホスト名がローカル環境なら、タイトル先頭に `🟢 ` を付ける（本番のタブと取り違えないため）
  - 組み込みで判定するもの: `localhost` / `*.localhost` / `*.local` / `*.test` / `*.internal` / `*.home.arpa`、`127.x.x.x` / `0.0.0.0` / `10.x.x.x` / `172.16〜31.x.x` / `192.168.x.x` / `169.254.x.x`、`[::1]` などの IPv6 ループバック・プライベートアドレス
  - オプションページで追加ホストを登録できる（1行1つ。`*.dev.example.com` でサブドメインをまとめて、`app.example.com:8080` でポート込みの指定も可）
  - 目印の文字（デフォルト 🟢）もオプションページで変更できる
- 例: `🟢 MyApp - ダッシュボード`（localhost:3000）/ `MyApp - ダッシュボード`（本番）
- ページ読み込み・タイトル変更のたびに付け直すので、SPA がタイトルを書き換えても追従する。💤・`[ラベル]` と併用時は `💤 🟢 [ラベル] タイトル` の順
- オプションページでオフにできる（オフにすると全 🟢 を外す）。判定は URL のホスト名のみで、ページ内容は読まない
- 💤 と同じ仕組みなので、休止中のタブには付けられない（読み込まれた時点で付く）

## インストール

1. `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」でこのディレクトリを選択

権限は `tabs` / `tabGroups` / `storage` / `scripting` / `alarms` / `contextMenus` と全サイトへのホスト権限。ホスト権限は 💤 マーク・`[ラベル]`・🟢 のタイトル書き換え（`document.title` の変更）だけに使い、ページの閲覧内容は読み取らない（ラベルと 🟢 の判定は URL のみから行う）。

## 既知の制限（プロトタイプ）

- スナップショットは `storage.session` 保持のため、**Chrome再起動でMRUモードは解除扱い**になる（再起動後は元に戻せない。順序はChromeが最後の状態を復元するのでMRU並びのまま残る）
- MRUモード中に新しく作ったウィンドウはスナップショットがないため、OFF時はそのままの並びで残る
- ピン留めタブは常に対象外
- 復元されるグループは「作り直し」なので、グループIDに依存する他拡張とは相性が悪い可能性あり
- 💤 マークは content script 方式のため、`chrome://` 等の保護ページと**メモリセーバーで休止中（discarded）のタブには付けられない**（放置タブほど休止されやすいのが弱点）。ページ自身がタイトルを書き換えるSPAでは一時的に消えることがあるが、次回チェックで再付与される
